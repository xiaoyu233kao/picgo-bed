# picgo-bed

个人网站「烤鱼日常」（https://xiaoyu233kao.github.io/ ）专用图床仓库，通过 PicGo 或 GitHub 管理站点公开展示的旅行与画廊照片。

## 使用规范

- 博客所有公开文章与画廊照片均统一上传至本仓库并通过 `https://raw.githubusercontent.com/xiaoyu233kao/picgo-bed/main/<文件名>` 引用，避免本地素材目录误删影响线上网站显示。
- 仅存放拟公开展示的照片文件，严禁上传私人随笔或未公开素材。
- 文件名统一使用小写扩展名 `.jpg` 及语义化前缀：
  - 画廊照片：`gallery-japan-NNN.jpg`（123 张）、`gallery-russia-NNN.jpg`（69 张）
  - 游记配图：按章节与序号命名（当前共 86 张，对应日本第一章 33 张、日本第二章 22 张、俄罗斯第三章 31 张）
